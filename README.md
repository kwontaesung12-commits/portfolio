- **접근:** 데이터 증강, 클래스 가중치 조정으로 미탐 오류 최소화

- **기술스택:** `Python`, `CNN`, `VGG16`, `ResNet50`, `EfficientNetB0`

- **특징:** Grad-CAM으로 병변 위치 시각화, 질환 중증도 6단계 분류  
- **구현:** 기업 연계 프로젝트로 상용 서비스 수준으로 고도화 및 배포  
- **기술스택:** `Docker`, `AWS`, `CNN`, `Grad-CAM`, `FastAPI`, `MySQL`, `PyTorch`, `Git`, `GitHub`
- 배운점 : 딥러닝 논문 활용법, 아키텍쳐 설계법, fastAPI를 활용한 백엔드 구성, aws 서빙, 데이터 수집 및 전처리, 전체 아키텍쳐 설계

[납치 감지 자동알림 모바일 서비스]
- **목표:** 스마트폰 GPS 및 모션 데이터를 기반으로 납치 상황 자동 감지
- 내용: gps, 자이로 센서로 수집한 스마트폰 사용자의 움직임으로 위협을 감지하는 모델을 구현
- **데이터:** GeoLife GPS Trajectories Dataset
